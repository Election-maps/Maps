# 🏛️ AP Election GeoPortal | పోలింగ్ కేంద్రాలు & రూట్ మ్యాప్స్ వెబ్ అప్లికేషన్
> **ZPTC & MPTC Segments - Election Polling Stations, Route Logistics & Police Security GIS Portal**

ఒక ఆధునిక, వేగవంతమైన మరియు అధునాతన (Advanced) సింగిల్ పేజ్ వెబ్ అప్లికేషన్ (SPA). ఇది ఎన్నికల పోలింగ్ కేంద్రాలు, రూట్ మ్యాప్స్, సెన్సిటివిటీ కేటగిరీలు, పోలీస్ బందోబస్తు మోహరింపు మరియు బూత్ లెవల్ ఆఫీసర్స్ (BLO) సంప్రదింపులను సులువుగా వీక్షించడానికి, నావిగేట్ చేయడానికి ఉపయోగపడుతుంది.

ఈ ప్రాజెక్ట్ **GitHub Pages** లో నేరుగా హోస్ట్ చేసుకోవడానికి మరియు కంప్యూటర్‌లో `index.html` ఫైల్‌ను డబుల్ క్లిక్ చేసి ఆఫ్‌లైన్ / లోకల్‌గా రన్ చేయడానికి అనుకూలంగా రూపొందించబడింది.

## 🌟 ముఖ్య లక్షణాలు (Key Features)

### 1. 🗺️ ఇంటరాక్టివ్ GIS మ్యాప్ (Interactive Leaflet Map & Clustering)
- **1,328+ పోలింగ్ కేంద్రాలు**: మొత్తం పోలింగ్ లొకేషన్లు కలర్-కోడెడ్ పిన్లతో మ్యాప్‌లో కనిపిస్తాయి.
  - 🟢 **సాధారణ (Normal)**: 886 కేంద్రాలు
  - 🟡 **సెన్సిటివ్ (Sensitive)**: 247 కేంద్రాలు
  - 🔴 **హైపర్ సెన్సిటివ్ (Hyper Sensitive)**: 186 కేంద్రాలు (హై-అలర్ట్ పల్స్ ఎఫెక్ట్‌తో)
- **శాటిలైట్ & స్ట్రీట్ వ్యూ**: Esri Satellite Imagery మరియు CartoDB Street Maps మధ్య ఒకే క్లిక్‌తో మారవచ్చు.
- **క్లస్టరింగ్ (Marker Clustering)**: ఎక్కువ సంఖ్యలో ఉన్న పిన్లను వేగంగా జూమ్ చేసి చూడటానికి స్మార్ట్ క్లస్టరింగ్.

### 2. 🛣️ రూట్ ప్లానర్ & డైనమిక్ రూట్ లైన్స్ (Sequential Route Navigation)
- ప్రతి మండలానికి సంబంధించిన రూట్ నంబర్ ఎంచుకున్నప్పుడు, ఆ రూట్ పరిధిలోని పోలింగ్ కేంద్రాలన్నీ వరుస క్రమంలో కనెక్ట్ అవుతూ **యానిమేటెడ్ రూట్ లైన్ (Polyline)** కనిపిస్తుంది.
- ప్రతి స్టాప్‌కు నంబరింగ్ (Stop 1, Stop 2, Stop 3...) ఇవ్వబడుతుంది.

### 3. 📍 లైవ్ జీపీఎస్ నావిగేషన్ (Live User Geolocation & Google Maps)
- **"నా లొకేషన్" (Find My Location)**: ఫీల్డ్‌లో ఉన్న పోలీస్ లేదా ఎన్నికల అధికారి తన ప్రస్తుత స్థానాన్ని లైవ్ జీపీఎస్ ద్వారా తెలుసుకోవచ్చు.
- ఏదైనా పోలింగ్ కేంద్రానికి **గూగుల్ మ్యాప్స్ టర్న్-బై-టర్న్ డ్రైవింగ్ డైరెక్షన్స్** ఒక్క క్లిక్‌తో ఓపెన్ అవుతాయి.
- మీ ప్రస్తుత లొకేషన్ నుండి ఆ పోలింగ్ కేంద్రానికి దూరం (KM) తక్షణమే లెక్కించబడుతుంది.

### 4. 🔍 మల్టీ-లెవల్ ఫిల్టరింగ్ & లైవ్ సెర్చ్ (Instant Search & Filters)
- **32 మండలాలు (ZPTC Segments)** వారీగా ఫిల్టర్.
- ఎంచుకున్న మండలానికి సరిపడే **MPTC సెగ్మెంట్లు** మరియు **రూట్ నంబర్లు** ఆటోమేటిక్‌గా అప్‌డేట్ అవుతాయి.
- పోలింగ్ కేంద్రం పేరు, రూమ్ నెంబర్, BLO ఫోన్ నెంబర్ లేదా అధికారి పేరు ద్వారా తక్షణ సెర్చ్.

### 5. 📊 ఎనలిటిక్స్ & సెక్యూరిటీ డాష్‌బోర్డ్ (Chart.js Visualizations)
- **మొత్తం ఓటర్లు**: 16,36,593 (1.63M)
- **పోలీస్ బలగాల మోహరింపు**: 12 SI, 263 ASI/HC, 886 PC, 396 HG (మొత్తం 1,557 మంది).
- డోనట్ & బార్ చార్ట్‌ల ద్వారా సెన్సిటివిటీ మరియు మండలాల వారీగా ఓటర్ల గ్రాఫ్‌లు.

### 6. 🚨 అత్యవసర సంప్రదింపులు & డైరెక్టరీ (Police & BLO Helpline)
- సర్కిల్ ఇన్‌స్పెక్టర్లు (CI), సబ్-ఇన్‌స్పెక్టర్లు (SI), మరియు BLOల ఫోన్ నెంబర్లు.
- డైరెక్ట్ **ఫోన్ కాల్ (`tel:`)** మరియు **వాట్సాప్ (`wa.me`)** బటన్లు.

### 7. 🌐 ద్విభాషా సపోర్ట్ & ఎక్స్‌పోర్ట్ (Bilingual Telugu/English & CSV Export)
- ఒకే క్లిక్‌తో తెలుగు మరియు ఇంగ్లీష్ భాషల మధ్య మారే వెసులుబాటు.
- ఫిల్టర్ చేసిన డేటాను మైక్రోసాఫ్ట్ ఎక్సెల్ (.csv) రూపంలో డౌన్‌లోడ్ చేసుకునే సదుపాయం.

## 🚀 GitHub లో అప్‌లోడ్ చేసి లైవ్ చేయడం ఎలా? (How to Deploy to GitHub Pages)

మీ ప్రాజెక్ట్‌ను GitHub లో ఉచితంగా హోస్ట్ చేసి ఎవరికైనా షేర్ చేయవచ్చు:

### స్టెప్ 1: GitHub లో కొత్త రిపోజిటరీ క్రియేట్ చేయండి
1. [GitHub.com](https://github.com) లోకి లాగిన్ అవ్వండి.
2. కుడివైపున పైన ఉన్న **+** బటన్ క్లిక్ చేసి **New repository** ఎంచుకోండి.
3. రిపోజిటరీ పేరు (ఉదాహరణకు: `election-geomaps`) ఇవ్వండి.
4. **Public** ఎంచుకుని **Create repository** క్లిక్ చేయండి.

### స్టెప్ 2: ఫైల్స్‌ను అప్‌లోడ్ చేయండి
మీ కంప్యూటర్‌లో Git ఉంటే కమాండ్స్ ద్వారా, లేదా నేరుగా బ్రౌజర్‌లోనే అప్‌లోడ్ చేయవచ్చు:
- GitHub వెబ్‌సైట్‌లో **"uploading an existing file"** లింక్ క్లిక్ చేయండి.
- ఈ ఫోల్డర్‌లోని అన్ని ఫైల్స్ (`index.html`, `app.js`, `app.css`, `data.js`, `data.json`, `README.md`) డ్రాగ్ & డ్రాప్ చేయండి.
- **Commit changes** బటన్ క్లిక్ చేయండి.

### స్టెప్ 3: GitHub Pages ఆన్ చేయండి
1. మీ GitHub రిపోజిటరీలోని **Settings** టాబ్‌పై క్లిక్ చేయండి.
2. ఎడమవైపు మెనూలో **Pages** ఆప్షన్‌ను ఎంచుకోండి.
3. **Build and deployment** విభాగంలో:
   - Branch: **`main`** (లేదా `master`) సెలెక్ట్ చేయండి.
   - Folder: **`/ (root)`** ఉంచండి.
4. **Save** బటన్ క్లిక్ చేయండి.
5. 1-2 నిమిషాల్లో మీ వెబ్‌సైట్ లైవ్ అవుతుంది! మీ వెబ్‌సైట్ లింక్ ఇలా ఉంటుంది:
   `https://<మీ-యూజర్‌నేమ్>.github.io/<రిపోజిటరీ-పేరు>/`
